# Hero product image upload folder

Upload the owner-provided, authentic hero product image into this folder.

## Required file

- Preferred filename: `SD-GL052.webp`
- Also accepted if needed: `SD-GL052.png` or `SD-GL052.jpg`

Keep the original product image and its real product identity. Do not upload a different SKU as a substitute, generate a replacement, or alter catalog/API data to make an audit pass.

After uploading, notify the storefront maintainer of the exact filename and commit. The storefront can then reference this owner-provided asset directly after visual verification. This upload folder does not itself change the live hero or bypass any catalog/API checks.

## Upload through GitHub

Open this folder on branch `fix/liquid-glass-audit-2026-10-19`, choose **Add file → Upload files**, select the image, and commit it to this same branch. Do not upload to `main` and do not deploy Production.
