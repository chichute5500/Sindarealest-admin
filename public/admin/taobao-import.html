Đăng nhập SinDarealest Admin

Đăng nhập quản trị trên chính website SinDarealest. Công cụ không yêu cầu mật khẩu Taobao.

1. Dán link Taobao và lấy ảnh

Mở sản phẩm

Tự lấy ảnh sử dụng API Taobao chính thức khi tài khoản ứng dụng đã được cấp quyền. Đăng nhập Chrome riêng lẻ không cấp quyền API. Nhận cả link rút gọn e.tb.cn và nguyên đoạn tiếng Trung; một số link vẫn cần Taobao cho phép giải mã.

Dán link và bấm “Tự lấy ảnh từ link”. Hệ thống sẽ báo rõ nếu API chưa được kết nối.

Chưa có link sản phẩm.

2. Ảnh đã lấy được / chọn ảnh bổ sung

Ảnh đầu tiên là ảnh đại diện. Bấm ↑ ↓ để sắp xếp, ✕ để loại khỏi danh sách.

Chưa chọn ảnh.

3. Thông tin sản phẩm

✓ Sản phẩm chỉ được tạo ở trạng thái ẨN / BẢN NHÁP. Không công khai lên web khi chưa duyệt.
Mở Admin

Ảnh tự động chỉ được lấy qua API Taobao chính thức đã cấp quyền. Không đọc mật khẩu, cookie hay phiên đăng nhập Taobao.
